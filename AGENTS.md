Агент: Добавление функции отписки (Практика 3, demo)

Назначение

- Описать и подготовить кодовую фичу для существующей базы Практики 3: добавить функцию `unsubscribe` в учебный сервис `demo` и покрыть её тестами. Реализацию кода выполняет агент по этому документу.

Область (изменения кода)

- Изменения строго в файлах demo-сервиса Практики 3:
  - `practices/practice_03/lab/demo/service.py`
  - `practices/practice_03/lab/demo/test_service.py`
- Только стандартная библиотека Python 3.10+; структура Makefile уже существует.

Действующие правила

- Инструкции Практики 3 — `practices/practice_03/README.md`.
- Демо-сервис — `practices/practice_03/lab/demo/README.md`.
- Make-цели — `practices/practice_03/lab/Makefile` (install, test).

Интеграции и MCP

- Загрузи skill `practice-3-demo-unsubscribe`.
- MCP `lab-tester` (собственный stdio-tool) доступен для вспомогательных запросов. Перед началом работы выполни проверочный вызов метода `run_lab_tests` (любой простой запуск), чтобы подтвердить подключение. Достаточно зафиксировать факт успешного ответа.
- После внесения правок автопроверка запускается автоматически hook'ом и runner'ом: тесты выполняются через `make -C practices/practice_03/lab install` и `make -C practices/practice_03/lab test`, а результат возвращается агенту.

Описание задачи (что должен сделать агент)

- Добавить функцию `unsubscribe(name)` в `service.py`:
  - Пустые/пробельные имена: `ValueError("empty name")` (симметрия с `subscribe`).
  - Идемпотентность: удаление отсутствующего пользователя не ошибка; возвращается `{"unsubscribed": False}`.
  - Удаление существующего подписчика возвращает `{"unsubscribed": True}`.
- Дополнить unit-тесты в `test_service.py`:
  - Позитивный сценарий отписки.
  - Идемпотентная отписка отсутствующего пользователя.
  - Ошибка при пустом имени.

Критерии приёмки

- `make -C practices/practice_03/lab test` выполняется успешно.
- Новые тесты покрывают описанные случаи; существующие тесты не ломаются.
- Поведение функций `subscribe` и `unsubscribe` соответствует описанию.

Проверка

- Запуск:
  - `make -C practices/practice_03/lab install`
  - `make -C practices/practice_03/lab test`
- Негативные сценарии (для разработки):
  - Попытка отписки без имени должна вызвать `ValueError`.
  - Повторная отписка не должна бросать исключений и должна возвращать `{"unsubscribed": False}`.
