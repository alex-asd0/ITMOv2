# Отчёт 1. Атаки на исходный сервис

Цель: зафиксировать уязвимости исходной версии, указать функции, где они присутствуют, и продемонстрировать возможные злоупотребления.

1) SQL-инъекция и небезопасный доступ к профилям
- Функция: Shop.dispatch (ветка GET /profile)
- Проблема: f-строка с подстановкой параметра id в SQL без параметризации: SELECT ... WHERE id = {query.get('id')}
- Риск: SQLi, чтение чужих профилей (IDOR)
- Демонстрация: /profile?id=1 OR 1=1 возвращает все профили

2) SQL-инъекция и утечка при поиске
- Функция: Shop.dispatch (ветка GET /search)
- Проблема: LIKE '%{q}%' без параметризации
- Риск: SQLi, чтение всех записей

3) Незащищённый экспорт через заголовок X-Role
- Функция: Shop.dispatch (ветка GET /admin/export)
- Проблема: доверие к произвольному заголовку X-Role; роль не берётся из сессии
- Риск: эскалация привилегий простым добавлением X-Role: staff

4) Несанкционированное чтение файлов
- Функция: Shop.dispatch (ветка GET /files)
- Проблема: путь строится из user и path; доступ не проверяет владельца; можно читать чужие чеки и private/
- Риск: disclosure чужих данных

5) Манипуляция ценой заказа
- Функция: Shop.dispatch (ветка POST /orders)
- Проблема: сервер принимает произвольный price из тела
- Риск: занижение цены

6) XSS в представлении отзывов
- Функция: Shop.dispatch (ветка GET /reviews/view)
- Проблема: прямой вывод текста отзывов в HTML без экранирования
- Риск: отражённая/хранимая XSS

7) Утечка логов и чувствительных заголовков
- Функция: Shop.dispatch (ветка GET /debug/logs)
- Проблема: без авторизации, содержит тела и заголовки (включая X-Token)
- Риск: раскрытие токенов, тел запросов

8) Выполнение опасных инструментов без авторизации
- Функция: Shop.dispatch (ветка POST /assistant/execute)
- Проблема: нет проверки роли/владения; клиент может export_profiles и delete_tree
- Риск: утечка профилей, удаление файлов

9) Контекст помощника содержит SQL-инъекцию/IDOR
- Функция: Shop.dispatch (ветка GET /assistant/context)
- Проблема: f-строка с order_id; включает отзывы с возможной prompt injection
- Риск: LLM может выполнить вредные действия; SQLi на order_id

Примечание: Тесты проходят на исходном сервисе, но уязвимости остаются доступны через HTTP.
