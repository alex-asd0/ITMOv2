# Модель угроз Mini Shop (Практика 6)

## Контекст и границы
- Локальный учебный сервис на 127.0.0.1
- Данные: профили, заказы, отзывы, одноразовые файлы в песочнице
- Роли: customer (alice, bob), staff
- AI-помощник возвращает решение (tool, arguments), сервер исполняет инструменты

## Предположения и активы
- Конфиденциальность профилей, чеков клиентов
- Целостность заказов и цен
- Ограничение файловых операций рамками пользователя
- Инструменты исполняются только в пределах полномочий сессии

## Потенциальные нарушители
- Аутентифицированный клиент (alice/bob), злоумышленник
- Внутренний нарушитель (подмена заголовков)
- Prompt injection в отзывах

## Угрозы (входящие в REPORT_01)
- SQL-инъекции в SELECT (profile/search/context)
- IDOR/несанкционированный доступ к профилям/заказам
- Подмена роли через X-Role
- Чтение чужих/приватных файлов через traversal внутри песочницы
- Манипуляция ценой заказа через клиентский price
- XSS в /reviews/view
- Неограниченный доступ к журналам и утечка токенов
- Неограниченное исполнение инструментов помощника (read/export/delete)

## Меры защиты (реализуются в фиксе)
- Параметризованные запросы
- Сессия определяет id и роль; игнорировать X-Role
- Контроль доступа к профилям/заказам/логам
- Белые списки путей файлов; собственная квитанция
- Фиксация цены с каталога на сервере
- Экранирование HTML в представлении отзывов
- Политика на инструменты помощника: авторизация по роли/владению
