# Few-shot

- Артефакт Практики 1: ADR (practices/practice_01/adr.md)
- Что хотим улучшить: статус и критерий принятия; явные «Решение + Как проверим» по SEC-1, API-1, REL-1, OUT-1/QA-1 и OBS-1; убрать дубли в «Последствиях»; расширить схему по правилам; заполнить раздел «Как использовали AI».

## Примеры

### Хороший результат

- Статус: proposed; есть критерий перехода в accepted через tests_*.
- Решение: перечислены шаги по API-1/SEC-1/REL-1/OUT-1/QA-1/OBS-1 и «Как проверим» со ссылками на tests_unit.md, tests_integration.md, tests_e2e.md, tests_load.md.
- Последствия: кратко, без дублирования; главный риск и способ проверки.
- Схема: последовательность по правилам с выходом JSON по OUT-1.

### Плохой результат

- «proposed / accepted» без критерия; нет «Как проверим» и ссылок на tests_*; последствия пустые или повторяются; схема без шагов правил; пустой раздел про AI.

## Запрос

Исправить practices/practice01/adr.md по правилам SEC-1, API-1, REL-1, OUT-1, QA-1, OBS-1 без новых фактов; не менять оригинал; убрать дубли; сохранить обновленный файл в practices/practice02/few_shot/updated_adr.md; заполнить practices/practice02/few_shot/experiment.md; дополнить по few_shot (этого эксперимента) practices/practice02/prompts.md , сохранив структуру.

## Что получили

Обновлённый ADR с:
- статусом proposed и критерием перехода в accepted через tests_*;
- блоком «Решение + Как проверим» по всем правилам;
- устранёнными дублирующими пунктами последствий;
- архитектурной схемой по API-1 → SEC-1 → REL-1 → OUT-1/QA-1 → OBS-1 → выход;
- заполненным разделом «Как использовали AI».

## Что изменили в исходном артефакте

- Файл и раздел: practices/practice_02/few_shot/updated_adr.md — статус, критерий принятия, «Решение + Как проверим», последствия, схема, раздел про AI.
- Изменение: добавлены критерии и проверки, ссылки на tests_*; удалены дубли; уточнены последствия и главный риск; схема расширена по правилам.
- Как проверили: соответствие правилам и тестам из practices/practice_01/tests_*. Сопоставлено с CASE.md и P1-02.md.
- Что отклонили: любые новые факты вне источников; предположения о реализации, не подтверждённые CASE.md/P1-02.md; дублирующие формулировки.
