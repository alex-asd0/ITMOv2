# ADR: решение для первого рабочего сценария

- Статус: proposed
- Критерий перехода в accepted: пройдут проверки из tests_unit.md, tests_integration.md, tests_e2e.md, tests_load.md на соблюдение SEC-1, API-1, REL-1, OUT-1/QA-1 и OBS-1
- Дата: 2026-09-09
- Ответственные: команда разработки сервиса ревью

## Контекст

Сервис получает diff PR и пересылает его во внешний LLM. По CASE.md действуют правила SEC-1, API-1, REL-1, OUT-1, SCOPE-1, QA-1, OBS-1. Текущая версия нарушает несколько из них.

## Решение + Как проверим

- API-1: отклонять diff > 20 000 символов (413). Как проверим: tests_integration.md «Превышение размера diff», tests_e2e.md «Граничный: 20000»/«Позитивный».
- SEC-1: редакция секретов (REDACTED) и изоляция diff в промпте. Как проверим: tests_unit.md «SEC-1: Редакция секретов».
- REL-1: timeout 10s, контролируемый ответ без 500. Как проверим: tests_integration.md «Таймаут/ошибка LLM», tests_e2e.md «Негативный: ошибка LLM», tests_load.md «95-й перцентиль < 1s».
- OUT-1/QA-1: summary, risks≤3 (file, line, evidence, risk), checks; отбрасывать риски без evidence. Как проверим: tests_unit.md «OUT-1: risks<=3 и evidence», tests_e2e.md «Позитивный: JSON по OUT-1».
- OBS-1: логировать только request_id, длительность, статус; без diff/ответа. Как проверим: интеграционные сценарии; ручная проверка логов (Unconfirmed автотестами).

## Рассмотренные альтернативы

| Альтернатива | Почему не выбрали сейчас |
|---|---|
| Передавать diff как есть | Нарушает SEC-1 и повышает риски утечки |
| Свободный текст вместо OUT-1 | Непригодно для автоматической проверки и нарушает OUT-1 |
| Отсутствие таймаута | Нарушает REL-1, ведёт к нестабильности |

## Последствия и главный риск

- Положительные:
  - Соблюдение SEC-1/API-1/REL-1/OUT-1/QA-1
  - Предсказуемый формат OUT-1
- Ограничения:
  - Накладные расходы на санитайзинг/валидацию и дисциплину логирования
- Главный риск:
  - Ложная/пропущенная редакция секретов; риск нарушения OUT-1 при сбоях
- Как проверим риск:
  - tests_unit.md (SEC-1), tests_integration.md/tests_e2e.md (формат OUT-1 при ошибках)
