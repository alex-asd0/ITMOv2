# Проблема и метрики

## Проблема

- Пользователь: внутренний клиент, вызывающий API сервиса ревью PR.
- Ситуация: нужно отправить diff в сервис и получить структурированное ревью с рисками и проверками.
- Что происходит сейчас: сервис отправляет diff во внешний LLM без редакции секретов и без ограничений размера; структура ответа не соответствует требуемой (OUT-1); отсутствует таймаут и контролируемая обработка ошибок; нет валидации входа на уровне API.
- Почему это мешает пользователю или бизнесу: риск утечки секретов (SEC-1), непредсказуемые затраты и DoS при больших diff (API-1), нестабильные ответы и невозможность автоматических проверок (OUT-1), таймауты/500-ошибки (REL-1), ухудшение эксплуатационных метрик и доверия.
- Что не входит в задачу: реализация безопасности уровня аутентификации/авторизации и интеграции с GitHub; изменение бизнес-логики вне описанных правил.

## Метрики

Выберите измеримые показатели, относящиеся к проблеме. Не используйте VTG, IRR, WACC, CSAT или другую метрику только ради названия.

| Метрика | Текущее значение или способ замера | Целевое изменение | Когда измеряем | Источник данных |
|---|---:|---:|---|---|
| Доля ответов, соответствующих OUT-1 | Ручная проверка P1-01/P1-02 | 100% соответствие | После внедрения фиксов | Ответ API, контракт |
| Доля отклонённых слишком длинных diff | Интеграционный тест с >20k символов | 100% запросов получают 413 | Тесты | Логи/ответы API |
| Утечки секретов в prompt | Проверка на тестовых токенах | 0 случаев | Тесты | Логи отсутствуют; проверка через фиктивный LLM |
| Ошибки 500 при сбоях LLM | Нагрузочный/интеграционный тест с симулированной ошибкой | 0; вместо этого контролируемый ответ | Тесты | Метрики API |

## Почему изменение метрики подтвердит решение проблемы

Повышение доли соответствия OUT-1 подтвердит структурированность и пригодность результата. 413 для длинных diff защитит от перерасходов и DoS. Отсутствие утечек секретов докажет соблюдение SEC-1. Нулевая доля 500 при ошибках LLM покажет соответствие REL-1 и улучшение стабильности сервиса.
