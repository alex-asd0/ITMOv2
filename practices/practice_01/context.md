## Context Pack для первого рабочего сценария

### Факты и правила

- SEC-1: перед отправкой во внешний LLM из diff удаляются секреты
- API-1: diff > 20 000 символов отклоняется с HTTP 413
- REL-1: таймаут LLM 10 секунд; ошибки превращаются в контролируемый ответ
- OUT-1: ответ содержит summary, массив risks (<=3) и массив checks; каждый риск с file, line, evidence, risk
- SCOPE-1: сервис только советует, не пишет код и не действует в GitHub
- QA-1: риск включается, только если подтверждён diff или правилом
- OBS-1: логируются request_id, длительность и статус; diff/ответ не логируются

### Формат входа и результата

- Вход: diff (строка) в теле запроса POST /api/reviews
- Результат: структурированный ответ по OUT-1 (summary, risks<=3, checks)

### Ограничения и запрещённые действия

- Нельзя логировать содержимое diff и ответа (OBS-1)
- Нельзя включать неподтверждённые риски (QA-1)
- Нельзя отправлять секреты во внешний LLM (SEC-1)
